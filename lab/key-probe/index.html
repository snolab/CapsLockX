Key Probe

What the foreground application actually receives, recorded in the browser, so it can be diffed against what clx's WH_KEYBOARD_LL hook logged for the same keystrokes. The gap between the two lists is exactly what clx suppressed or injected.

Turn on clx's hook log first, or there is nothing to diff against. Stop clx, then:
$env:CLX_DEBUG=1; C:\Users\snomi\CapsLockX\clx.exe
Hook lines land in %TEMP%\capslockx_hook.log and carry millisecond epoch timestamps — the same clock this page stamps events with, so the two align directly.
