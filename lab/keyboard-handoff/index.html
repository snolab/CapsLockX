Keyboard hand-off

Testing clx means pressing keys, and injected keys land in whatever window has focus. On a machine you are still using, that has meant your editor. Hand the keyboard over here instead: this window takes focus, the keystrokes land in this table, and the agent reads them from disk rather than asking you to copy anything back.

How this is used

  1. The agent opens this page and asks you to hand the keyboard over.
  2. You press Start the test and stop typing. This window keeps focus, so anything injected lands here and not in your work.
  3. The agent runs the test, then reads both this table and clx's own hook log — two independent records of the same keystrokes, which is what makes "clx never saw it" a finding rather than a guess.
  4. The banner turns green when the agent releases the keyboard. It also releases itself after five minutes, so a forgotten test cannot sit on your keyboard.

State lives in tmp/keyboard-handoff.json. Keys are recorded only between Start and release, and only code/key — enough to identify a keystroke, and it never leaves this machine.
